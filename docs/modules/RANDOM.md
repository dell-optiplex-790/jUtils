# jUtils Documentation - The "random" module

## About
The jUtils "random" module allows for generating random integers (WITHOUT decemals) in a range.

## Usage
`jUtils.random(min, max)` - Generates a random number from `min` to `max`. The number `max` must be bigger then `min` and both numbers must be defined and have the type `Number`. It returns a `Number` if it succeeds and `false` if it doesn't.
