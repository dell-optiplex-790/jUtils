# jUtils Documentation - The "array-pick" module

## About
The jUtils "array-pick" module picks a random item from the array specified.

## Usage
`jUtils.pick(array: Array): Any | false` - Picks a random item from array `array` and returns it. If the operation is not successful or the picked item ends up being `false` (if you're doing arrays of booleans for whatever reason), `false` is returned.
