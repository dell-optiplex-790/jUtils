# About
jUtils is a pure-ES5 utility library, which aims for a small file size and is also platform-independent.
This library is not to be confused with:
- [jQuery](https://jquery.com/)
- jUtils (the Java one)

# Contributions
Pull requests are welcome as long as they:
- don't use ES6+ JavaScript features
- add something that's actually useful (keep it in the `src/modules` folder if it's a module!)
- don't *use* or *aren't made by* the clankers (generative AI)
- don't use 3rd-party libs (as to not introduce supply-chain malware or licensing complications into the library)
- don't use other jUtils modules outside of core.js (as to not break builds that lack those modules)
- don't implement what is already in [base ES5](https://ecma-international.org/wp-content/uploads/ECMA-262_5th_edition_december_2009.pdf)
